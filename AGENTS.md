# AGENTS.md

This repo builds OpenWrt firmware for the CMCC RAX3000Q/QY router via GitHub Actions. It is **not** a traditional software project — there is no local build, test, lint, or typecheck workflow. Target platform: `ipq50xx` / `ipq50xx_32` (ARM32 Cortex-A7), QSDK 12.5 kernel (in-tree `qca/src/linux-5.4`).

## Status: mid-port from QSDK 11.5 -> QSDK 12.5

This repo was switched from `kkstone/immortalwrt-ipq50xx` (QSDK 11.5 + ImmortalWrt 21.02) onto a custom fork `QuickXand/qsdk` branch `rax3000q-port` based on QSDK 12.5.2783.2994. The port is a **scaffolded first pass** — the build is expected to **fail** in its current state and the goal of the next run is to harvest a `V=s` error log to drive the next port step. Things known to be incomplete:

- `ipq5000-cmcc-rax3000q.dts` was copied verbatim from `hzyitc/openwrt-redmi-ax3000@ipq50xx-qsdk-kernel-5.4-openwrt-21.02-qsdk-11.5.05.841.1029`. It still `#include`s `ipq5018.dtsi` (which in 12.5 only holds the PMU node — SoC nodes live in `arch/arm64/boot/dts/qcom/ipq5018.dtsi`); node labels referenced by `&q6v5_wcss`, `&wifi0`, `&wifi1`, `&tlmm`, `&q6v5_wcss` may not match the 12.5 kernel. The expected first failure is a DTS compile error in `arch/arm64/boot/dts/qcom/ipq5000-cmcc-rax3000q.dtb`.
- `ipq-wifi-cmcc_rax3000q` package + its binary BDF firmware are **not** ported yet — they live in the 11.5 fork's `package/firmware/ipq-wifi`. Device will boot without calibrated WiFi once firmware comes up.
- `target/linux/feeds/ipq50xx/base-files/{etc,lib}` for RAX3000Q (LED/network/upgrade scripts) are **not** ported — only the 12.5 stock Qualcomm AP defaults remain.
- `.config` here is a **minimal seed** (≈30 lines). It just locks target/subtarget/device and points at the in-tree kernel. The full config is regenerated by `make defconfig` inside the runner. Original 11.5 .config lives at `C:\Users\ROG\AppData\Local\Temp\opencode\qsdk-port\.config.qsdk11.5.bak` (out of tree, not committed).

## What lives where

- `.github/workflows/build-openwrt.yml` — the entire build pipeline; single source of truth.
- `.config` — minimal seed for `make defconfig` (target/subtarget/device + in-tree kernel pointer). Editing by hand is only for the seed; the full config lives in the runner's `openwrt/.config`.
- `diy-part1.sh` — runs before `./scripts/feeds update -a`. Currently near-empty.
- `diy-part2.sh` — runs after feeds install, before `make defconfig`. Package patching / config tweaks go here.
- `feeds.conf.default` — optional custom feeds file; the workflow moves it into the OpenWrt tree if present. Note: 12.5 tree's default `feeds.conf.default` already pins openwrt-23.05 feeds.

## How builds run

- Triggered manually (`workflow_dispatch`, optional `ssh` input to drop into a tmate session for debugging) or on a weekly cron (`0 8 * * 2` = Tuesday 08:00 Asia/Shanghai).
- Source: `https://github.com/QuickXand/qsdk` branch `rax3000q-port`. This is a fork of `everything411/qsdk@12.5.2783.2994` carrying the RAX3000Q DTS/image port on top. Do **not** repoint `REPO_URL`/`REPO_BRANCH` unless you understand the port currently lives only on that branch.
- Runs on `ubuntu-22.04`; the workflow frees disk by removing dotnet/llvm/android/node_modules etc. before installing build deps. Build artifacts and a GitHub Release (`RAX3000Q-YYYY.MM.DD-HHMM`) are uploaded on success. Old workflow runs (>1 day, keep 3) and old releases (keep 5) are auto-pruned.
- The 12.5 tree has the kernel **in-tree** at `qca/src/linux-5.4`. The 11.5-era Dropbox `dl/*.tar.xz` manual download step is gone — there is no separate kernel tarball fetch.

## Non-obvious workflow steps (do not reorder)

The workflow applies several feed swaps after cloning. They are not load-bearing for an ipq50xx NSS build per se, but inherited from the 11.5 setup:

1. **golang feed** — `feeds/packages/lang/golang` is replaced with `kenzok8/golang` branch `1.25`. Keep while any Go-based package is selected.
2. **node feed** — `feeds/packages/lang/node` is replaced with `sbwml/feeds_packages_lang_node-prebuilt` branch `packages-24.10`. Keep only if a node-based package is selected (default seed config has none).
3. **Pinned net packages** — `natmap`, `ddns-go`, `frp` are overwritten with copies pulled from `immortalwrt/packages@master` via jsdelivr. These target OpenWrt master and may or may not compile against the 12.5 tree's openwrt-23.05 feeds; drop the step if it breaks the build and the packages aren't in the seed config.

 The following 11.5-only steps have been **removed** and must stay removed:

- **luci-app-turboacc** Dropbox zip — the 12.5 tree ships its own LuCI; the old Dropbox URL is dead and the patch targets 11.5.
- **Dropbox kernel/backports tarballs** (`linux-5.4-qsdk-11.5.0.5.tar.xz`, `backports-...`) — 12.5 kernel is in-tree, these tarballs are not part of the 12.5 build.

## Editing guidance

- The only way to validate a change is to push and run the workflow (or trigger `workflow_dispatch` with `ssh=true` to inspect the runner). There is no local CI on Windows — and on Windows you also cannot clone the QSDK tree because of `aux.c`/`aux.h` reserved-name files; use `git config core.protectNTFS false` plus `--filter=blob:none` + sparse-checkout if you must.
- `make -j$(nproc) || make -j1 || make -j1 V=s` is the compile fallback chain — keep all three stages; only the final `V=s` run gives useful error output. **Capturing that V=s tail is the goal of the first post-port run.**
- Keep `TZ: Asia/Shanghai` — release tags and FILE_DATE timestamps depend on it.
- `klever1988/cachewrtbuild` with `mixkey: qsdk12.5-rax3000q` provides ccache. Changing the target/subtarget requires updating `mixkey` or cache hits will be poisoned.
- When iterating on the port, edit `QuickXand/qsdk`'s `rax3000q-port` branch (DTS, image macros, kernel Makefiles, base-files) — not this repo. This repo only carries the workflow + seed `.config`.
